## 摘要
实时长篇虚拟形象音视频生成需要因果连续的合成，同时保持音画同步和视觉一致性。将预训练的双向模型适配到该场景面临两个关键难题。首先，自回归地将生成块作为上下文复用会产生曝光偏差，导致在长序列生成中错误和视觉漂移逐渐累积。其次，当仅有有限的局部音视频上下文时，全局语音话语无法指示因果生成器下一步应生成哪个部分。我们提出了Vorch-Streamer，一个后训练框架，解决了这些挑战，并实现了实时长篇文本到音视频（T2AV）流式生成。我们构建了一个包含8万个虚拟形象片段的合成语料库，每个片段时长12-21秒，并首先使用混合的教师强制（Teacher Forcing）和扩散强制（Diffusion Forcing）训练一个因果生成器。接着，我们应用长时程自强制（Self Forcing）与DMD蒸馏，使模型暴露于自身的展开分布，同时保持预训练双向教师模型的质量。为显式控制语音进度，一个外部语言模型预测离散的25Hz语音规划标记，其连续特征对音频扩散分支进行条件约束，并使每个因果块与其应说的内容对齐。通过有界因果上下文和四步去噪，Vorch-Streamer以27.12 FPS的速率从文本联合生成音频和视频，超过24 FPS的实时播放速率，同时在长篇生成中保持了具有竞争力的音唇同步和强大的身份保持能力。

## Abstract
Real-time long-form avatar audio-video generation requires causal, continuous synthesis while maintaining audiovisual synchronization and visual consistency. Adapting a pretrained bidirectional model to this setting presents two key dilemmas. First, autoregressively reusing generated blocks as context creates exposure bias, causing errors and visual drift to accumulate over long rollouts. Second, a global speech utterance does not indicates a causal generator which portion should be spoken next when only limited local audio-video context is available. We present Vorch-Streamer, a post-training framework that addresses these challenges and enables real-time long-form Text-to-Audio-Video (T2AV) streaming. We construct a synthetic corpus of 80K avatar clips spanning 12-21 seconds and first train a causal generator with mixed Teacher Forcing and Diffusion Forcing. We then apply long-horizon Self Forcing with DMD distillation, exposing the model to its own rollout distribution while preserving the quality of the pretrained bidirectional teacher. To explicitly control speech progression, an external language model predicts discrete 25-Hz speech-planning tokens, whose continuous features condition the audio diffusion branch and align each causal block with the content it should speak. With bounded causal context and four-step denoising, Vorch-Streamer jointly generates audio and video from text at 27.12 FPS, exceeding the 24-FPS real-time playback rate while maintaining competitive audio-lip synchronization and strong identity preservation over long-form generation.

# Vorch-Streamer：将人类视听生成扩展到实时长篇流式生成

## 1. 核心问题与研究动机

- 实时长篇虚拟形象音视频生成是教育、娱乐、虚拟沟通和交互式智能体等场景的关键能力。
- 现有高质量的音频-视频扩散模型（如 LTX-2、Ovi 等）主要面向短时、离线片段，使用双向注意力，要求完整序列在去噪过程中可见，无法直接用于流式生成。
- 将双向预训练模型适配到因果流式生成面临两个核心难题：
  1. **曝光偏差**：自回归地复用自身生成结果作为上下文会导致误差和视觉漂移随时间累积。
  2. **全局语音条件与因果生成的失配**：文本提示描述整段话语，但因果生成块只能访问有限的局部音视频上下文，无法可靠判断“现在应该说出哪一部分”，导致长时间生成时语音内容错位、甚至从话语中间开始。
- 本文提出 **Vorch-Streamer**，一种后训练框架，将预训练的 LTX2.3 双向音视频扩散模型改造为实时、长篇、文本驱动的因果流式生成器。

## 2. 方法论

整体流程分为三个阶段，外加一个显式语音规划模块：

### 2.1 合成虚拟形象语料
- 使用预训练的 LTX2.3 双向模型合成 **80K 个音视频片段**，时长 12–21 秒。
- 这些样本由同一个基础模型生成，因此与初始化模型的分布一致，可为后训练提供对齐的视听监督。

### 2.2 因果音视频流式生成（Stage 2：混合 Teacher Forcing / Diffusion Forcing）
- 将音视频隐变量划分为同步的块：每块约 3 个视频隐帧（对应1秒）+ 25 个音频隐 token；由于因果 VAE 对齐，第一块额外包含 1 帧和 1 个 token。
- 块内保留双向注意力，块之间采用因果注意力。
- 训练时每个块可关注前 3 个块（持久身份/场景上下文）和最近 3 个前序块（运动上下文）。
- 对历史序列采用 10% Teacher Forcing（保留干净历史）和 90% Diffusion Forcing（历史被加噪破坏），增强模型对自身生成历史中不完美内容的鲁棒性。
- 训练损失为标准音视频 flow-matching 损失：
  - \( L_{CF} = \sum_{m\in{v,a}} \lambda_m \|\hat{v}_m - (\epsilon_m - x^m_0)\|_2^2 \)

### 2.3 长时程 Self Forcing + DMD 蒸馏（Stage 3）
- 学生模型从 Stage 2 初始化，自回归地生成 12–21 秒的长序列，使用与推理一致的有界 KV-cache 窗口。
- 冻结原始双向 LTX2.3 作为 “real-score” 教师，训练一个可学习的双向 “fake-score” 模型估计学生分布。
- DMD 更新方向：\( g_m \propto p_{fake}^m - p_{real}^m \)，即让学生输出靠近教师分布、远离当前学生分布。
- 学生优化目标为 stop-gradient 的代理损失：
  - \( L_{DMD} = \sum_{m\in{v,a}} \frac{\lambda_m}{2} \|\tilde{x}^m_0 - \mathrm{sg}(\tilde{x}^m_0 - g_m)\|_2^2 \)
- fake-score 模型在 detach 的学生 rollout 上按标准 flow-matching 目标更新；学生与 fake-score 交替更新，保持 DMD 方向有效。

### 2.4 LLM 语音规划
- 使用 Fun-CosyVoice LLM 预测 25 Hz 的离散语音规划 token（每个对应 40 ms）。
- 通过预训练 lookup table（LUT）和可学习投影将 token 转换为连续规划特征。
- 规划特征通过额外的语音交叉注意力层注入音频分支；每个块只能关注本块时间范围内的规划特征。
- 通过可学习门控将语音特征输出与原文本到音频交叉注意力输出进行自适应融合：
  - \( h_a^\ell \leftarrow h_a^\ell + \mathrm{sigmoid}(g^\ell) \mathrm{Attn}_{speech}^\ell(h_a^\ell, e_s) \)
- 引入可学习的“静音 token”，使模型具备显式倾听能力，支持语音打断和切换，而不必在流开始前固定完整未来话语。

## 6. 主要结论与发现

- Vorch-Streamer 在单张 H200 上达到 **27.12 FPS**，是唯一超过 24 FPS 实时播放速率的原生 T2AV 模型。

## 7. 优点

- **问题拆解清晰**：将“双向到因果”的转换与“短时到长时”的转换分离，两阶段训练各司其职。
- **方法实用性强**：后训练方案能够复用强大的预训练双向模型，避免从头训练大规模因果模型。
- **显式语音规划设计新颖**：将“说什么、何时说”与“怎么说”解耦，支持打断/切换语音，比单纯依赖文本窗口的方法更可靠。
- **长期稳定性验证扎实**：同时使用端点变化、完整时间曲线和定性帧对比，避免短期评测造成的误判。
- **计算可控**：有界 KV-cache 窗口使内存不随序列长度增长，并支持训练与推理行为一致。

## 8. 不足与局限

- **数据局限性**：80K 语料全部由 LTX2.3 合成，缺少真实人类音视频数据，可能限制跨域泛化能力。
- **评测时长仍有局限**：约 2 分钟长时生成，对更长时间的“无限交互”未作验证。
- **部分基线不公平/不完全**：OmniForcing 和 Hallo-Live 仅评估 30 秒；TIA2V 基线使用外部音频和首帧，不能直接衡量 T2AV 能力。
- **打断/切换能力未做量化评测**：论文声称支持语音打断和切换，但实验主要基于完整话语的连续生成。
- **规模化成本较高**：训练需要 64/32 张 H200，且需要 22B 级别模型，部署门槛较高。
- **缺少与真实交互系统的对比**：如 Wan-Streamer 等强调交互延迟的模型未在标准化长序列质量评测中比较。
