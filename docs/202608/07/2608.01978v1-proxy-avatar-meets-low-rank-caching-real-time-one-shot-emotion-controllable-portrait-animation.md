## 摘要
基于扩散的生成模型推动了音频驱动的人像动画的显著进展，但实现具有丰富情感表达的实时一次性生成仍具挑战性。现有方法常面临情感感知运动先验不足以及多步去噪过程中外观计算成本高昂的问题。为解决这些问题，我们提出代理化身遇上低秩缓存（Proxy Avatar Meets Low-Rank Caching），一种用于实时一次性情感可控人像动画的级联框架。我们的方法不直接从音频生成目标人像，而是使用基于高斯的情绪代理化身作为可复用的运动生成器，该化身在单一身份上训练一次，即可从音频和情感标签生成富有表现力的驱动视频。由于代理化身仅提供运动而非目标外观或几何信息，一个大规模的一次性重定向模型进一步从代理表演中提取与身份无关的运动，并将其适配到任意目标人像。为提高推理效率，我们引入了带低秩缓存的零样本外观复用，该机制在初始去噪步骤缓存参考外观特征，并使用轻量级低秩适配器建模后续特征变化。大量实验表明，我们的方法实现了更强的情感表现力、更好的身份保持动画效果，并显著降低了推理成本，从而实现实时一次性人像动画。

## Abstract
Audio-driven portrait animation has advanced rapidly with diffusion-based generative models, yet real-time one-shot generation with expressive emotion control remains challenging. Existing methods often suffer from insufficient emotion-aware motion priors and expensive appearance computation during multi-step denoising. To address these issues, we propose Proxy Avatar Meets Low-Rank Caching, a cascaded framework for real-time one-shot emotion-controllable portrait animation. Instead of directly generating the target portrait from audio, our method uses a Gaussian-based emotion proxy avatar as a reusable motion generator, which is trained once on a single identity to produce expressive driving videos from audio and emotion labels. Since the proxy avatar only provides motion rather than target appearance or geometry, a large-scale one-shot retargeting model further extracts identity-independent motion from the proxy performance and adapts it to arbitrary target portraits. To improve inference efficiency, we introduce zero-shot appearance reuse with low-rank caching, which caches reference appearance features at the initial denoising step and models subsequent feature variations using lightweight low-rank adapters. Extensive experiments demonstrate that our method achieves stronger emotional expressiveness, better identity-preserving animation, and substantially reduced inference cost, enabling real-time one-shot portrait animation.

## 1. 论文核心问题与整体含义

### 研究背景
- 音频驱动的人像动画（Audio-driven Portrait Animation）是数字人、人机交互等应用中的核心技术，目标是根据语音驱动一张静态人像生成动态说话视频。
- 现有基于扩散模型的方法虽在画质与唇形同步上取得不错效果，但存在两大核心瓶颈：
  - **情感运动先验不足**：难以从音频中有效解耦并生成丰富、可控的情感表达（如惊讶、轻蔑等）。
  - **推理成本过高**：扩散模型多步去噪过程中，参考图像的外观特征被反复提取和计算，存在大量冗余计算，难以满足实时性要求。

### 论文核心问题
如何在一个统一框架内同时实现：
1. 强的情感可控性与表现力；
2. 对任意目标人像的一次性（one-shot）迁移能力；
3. 在消费级 GPU 上实时推理。

### 整体研究思路
作者从“分工协作”的视角重新设计框架：不要求单一模型同时承担情感表达、身份适配和高效合成三个任务，而是将其**解耦为三个级联阶段**，每个阶段解决一个明确的瓶颈。该框架的核心含义在于：**将“运动生成”与“外观合成”彻底分离**——先用高斯代理化身生成身份无关的丰富情感运动，再用一次性重定向模型将运动迁移到任意人像，最后用低秩缓存压缩外观计算的冗余。

## 2. 方法论：核心思想、关键技术细节与流程

### 总体框架
整个框架由三个级联阶段组成：
- **阶段一**：3D 高斯情感代理化身（3D Gaussian-based Emotion Proxy Avatar）——生成情感驱动视频；
- **阶段二**：一次性人像运动驱动模块（One-Shot Portrait Motion Driving Module）——将代理运动迁移到任意目标人像；
- **阶段三**：外观冗余蒸馏（Appearance Redundancy Distillation）——减少扩散推理的冗余计算。

### 阶段一：3D 高斯情感代理化身

**核心思想**：在单一身份上训练一次一个高斯代理化身，将音频与情感标签转化为显式的、情感丰富的驱动视频。该视频仅供阶段二使用，不直接作为目标输出，因此不要求目标外观。

**关键技术细节**：

1. **高斯表示**：代理化身由一组 3D 高斯（位置、旋转、尺度、颜色、不透明度）构成，通过投影与 alpha 合成渲染图像，支持高保真实时渲染。

2. **音频-情感运动分解**：将代理运动分解为：
   - 中性语音运动（m_neu，捕捉音素驱动的口型动作）
   - 情感相关残差运动（Δm_emo，建模眉毛、脸颊、眼睑、嘴角等情感区域动态）
   
   这一分解防止情感分支重复学习音素口型，使其专注于情感表达。

3. **空间-音频-情感联合注意力**：通过多层交叉注意力与前馈网络，将空间查询与音频特征、情感特征融合，建模面部区域、语音内容与情感状态之间的相互依赖。

4. **情感感知高斯形变**：用 MLP 回归每个高斯属性的偏移量（位置、旋转、尺度、颜色、不透明度），在情感空间中完成高斯形变与渲染。

**作用**：代理化身训练完成后，可实时渲染情感驱动视频，为后续提供显式且可控的运动载体。

### 阶段二：一次性人像运动驱动模块

**核心思想**：代理视频虽含丰富运动信息，但仍带有代理身份的外观与几何特征。因此需要一个在大规模数据上训练的一次性动画模型，从中提取**与身份无关的运动线索**，并适配到任意目标人像。

**两个控制器**：

1. **运动控制器（Motion Controller）**：
   - 用运动编码器提取代理帧的隐式面部运动表示（口型、眼部运动、局部表情）；
   - 通过交叉注意力注入去噪网络的空间层；
   - 作用：传递局部面部动态，避免对代理外观的依赖。

2. **姿态控制器（Pose Controller）**：
   - 从代理帧和参考人像中提取 3D 隐式关键点及姿态参数（旋转、平移、尺度）；
   - 通过姿态重定向公式将代理姿态适配到目标人像的几何结构上；
   - 作用：提供头部运动与粗粒度面部布局的显式几何引导，与隐式运动特征互补。

### 阶段三：外观冗余蒸馏

**核心思想**：一次性人像动画中，参考图像固定不变，其身份、纹理、背景在生成过程中基本稳定。传统方法却在每个去噪步骤重复提取参考外观特征，造成大量冗余计算。该模块通过“少步蒸馏 + 低秩外观缓存”压缩计算。

**关键技术细节**：

1. **少步外观蒸馏**：将原始多步采样过程蒸馏为一个紧凑的少步采样调度（由 K 个时间步组成，K ≪ N），学生模型沿蒸馏后的时间步渐进去噪并直接预测干净潜变量。

2. **低秩外观复用（Low-Rank Caching）**：
   - 仅在第一个蒸馏步骤计算完整的参考外观特征 F1；
   - 后续步骤将参考特征近似为 F1 加上一个低秩残差（ΔF_j ≈ A_j B_j，其中 A、B 为轻量级可学习矩阵，秩 r 远小于特征维度）；
   - 对多层特征金字塔逐层应用该近似。

3. **外观特征蒸馏损失**：通过 stop-gradient 操作，让低秩近似特征逼近原始完整外观特征，保证近似质量。

### 训练目标
- 阶段一：包含重建与正则化目标；
- 阶段二：包含 MSE、LPIPS、区域/全局对抗损失及 SyncNet 唇形同步损失；
- 阶段三：最终蒸馏损失 = 少步蒸馏损失 + 权重 × 外观特征蒸馏损失。

## 7. 优点

1. **创新的级联框架设计**：将运动生成、身份适配、效率优化解耦为三个独立阶段，各阶段职责清晰，整体系统逻辑自洽。
2. **高斯代理化身只需训练一次**：在单一身份上训练一次即可复用于任意目标人像，避免了多身份情感模型训练的高成本。
3. **身份无关运动提取**：通过运动控制器与姿态控制器的双通道设计，显式分离局部表情与全局姿态，有效避免了代理身份外观对目标身份的干扰。
4. **低秩外观缓存的巧妙设计**：利用参考图像在去噪过程中外观特征变化小且结构化的特性，用轻量级低秩残差替代完整的外观特征重计算，在保持质量的同时大幅降低推理成本。
