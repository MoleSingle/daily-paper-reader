## 摘要
实时长时虚拟人音视频生成要求因果、连续的合成，同时保持音视频同步和视觉一致性。将预训练的双向模型适配到该场景面临两个关键难题。首先，自回归地将生成的块作为上下文复用会产生曝光偏差，导致长时间生成中误差和视觉漂移不断累积。其次，在仅有限局部音视频上下文可用时，全局语音语句无法指示因果生成器下一步应生成哪部分内容。我们提出了一种后训练框架 Vorch-Streamer，它解决了上述挑战，并实现了实时长时文本到音视频（T2AV）流式生成。我们构建了一个包含8万段时长12至21秒的虚拟人片段的合成语料库，首先使用混合教师强制和扩散强制训练因果生成器。随后应用长时程自强制与DMD蒸馏，使模型暴露于其自身的生成分布，同时保留预训练双向教师模型的质量。为显式控制语音进度，外部语言模型预测离散的25Hz语音规划token，其连续特征条件化音频扩散分支，并将每个因果块与其应播报的内容对齐。凭借有界因果上下文和四步去噪，Vorch-Streamer以27.12 FPS从文本联合生成音频和视频，超过24 FPS的实时播放速率，同时在长时生成中保持具有竞争力的音频-唇形同步和强身份保持。

## Abstract
Real-time long-form avatar audio--video generation requires causal, continuous synthesis while maintaining audiovisual synchronization and visual consistency. Adapting a pretrained bidirectional model to this setting presents two key dilemmas. First, autoregressively reusing generated blocks as context creates exposure bias, causing errors and visual drift to accumulate over long rollouts. Second, a global speech utterance does not indicates a causal generator which portion should be spoken next when only limited local audio--video context is available. We present \textbf{Vorch-Streamer}, a post-training framework that addresses these challenges and enables real-time long-form Text-to-Audio-Video (T2AV) streaming. We construct a synthetic corpus of 80K avatar clips spanning 12--21 seconds and first train a causal generator with mixed Teacher Forcing and Diffusion Forcing. We then apply long-horizon Self Forcing with DMD distillation, exposing the model to its own rollout distribution while preserving the quality of the pretrained bidirectional teacher. To explicitly control speech progression, an external language model predicts discrete 25-Hz speech-planning tokens, whose continuous features condition the audio diffusion branch and align each causal block with the content it should speak. With bounded causal context and four-step denoising, Vorch-Streamer jointly generates audio and video from text at 27.12 FPS, exceeding the 24-FPS real-time playback rate while maintaining competitive audio--lip synchronization and strong identity preservation over long-form generation.

## 1. 论文的核心问题与整体含义

- **研究背景**：实时虚拟人音视频生成在在线教育、虚拟通信、交互式智能体等领域具有重要应用价值。现代音视频扩散模型虽能生成高质量且音画同步的内容，但大多面向短片段、离线生成场景。
- **核心挑战**：将预训练的双向注意力音视频扩散模型（LTX2.3）适配到实时长时流式生成时，面临两个关键困境：
  - **困境一（曝光偏差）**：自回归地将已生成块作为上下文复用时，训练（干净上下文）与推理（自生成上下文）之间存在分布偏移，导致误差累积、视觉漂移、长时生成不稳定。因果注意力下这一问题尤为严重。
  - **困境二（语音规划缺失）**：全局文本提示描述了完整语音内容，但每个因果块只能访问有限的历史上下文，无法判断当前块应生成哪段语音。若无显式语音规划，生成音频可能从话语中间开始或与语音进度错位。
- **核心含义**：论文主张从强大的双向基础模型出发，通过后训练将其转化为因果、实时、长时的流式音视频生成器，这比从头训练一个原生因果模型更为高效实用。

## 2. 论文提出的方法论

### 总体框架
Vorch-Streamer 是一个三阶段后训练框架，将预训练的双向 LTX2.3 模型转化为实时长时流式 T2AV 生成器，并引入外部 LLM 进行显式语音规划。

### 核心技术细节

- **阶段一：合成语料构建**
  - 使用预训练 LTX2.3 模型合成 8 万段高质量虚拟人音视频片段，时长 12–21 秒。
  - 采用模型自生成数据的原因：与初始化模型分布一致，提供模型一致的音视频监督信号。

- **阶段二：因果音视频流式训练（混合 Teacher Forcing / Diffusion Forcing）**
  - 将音视频潜变量划分为同步块：每块约 1 秒，含 3 个视频潜帧和 25 个音频潜 token。
  - 块内保留双向注意力以建模细粒度音视频交互；块间施加因果注意力。
  - 上下文窗口设计：每个块可访问前 3 个块（持久身份/场景上下文）和最近 3 个块（运动上下文），保证内存恒定。
  - 混合训练策略：10% 样本用干净历史（Teacher Forcing），90% 用噪声历史（Diffusion Forcing），降低训练-推理不匹配。
  - 采用流匹配目标优化：`LCF = Σ λm‖v̂m − (εm − x0m)‖²`

- **阶段三：长时程 Self Forcing + DMD 蒸馏**
  - 学生模型在 12–21 秒完整时间范围内自回归生成，暴露于推理时的自生成分布。
  - 冻结双向 LTX2.3 作为 real-score 教师模型；可训练双向 fake-score 模型估计学生分布。
  - DMD 更新方向：`g ∝ p_fake − p_real`；学生按 stop-gradient 代理损失优化。
  - 该阶段将双向教师的质量迁移到长因果轨迹中，支持 4 步去噪高效推理。

- **LLM 语音规划模块**
  - 使用 Fun-CosyVoice LLM 预测 25 Hz 的离散语音规划 token（每 token 对应 40 ms 规划单元）。
  - 扩展查找表加入可学习静音 token，支持静音监听与语音中断/切换。
  - 规划 token 经 LUT 和可学习投影转换为连续特征，通过新增的语音交叉注意力模块注入音频分支。
  - 与原有文本-音频交叉注意力的输出通过可学习门控进行自适应融合。
  - 这种解耦设计让扩散模型专注于音视频协同生成，而"说什么、何时说"由规划器负责。

## 6. 论文的主要结论与发现

- **实时性达标**：Vorch-Streamer 以 22.8B 参数在单张 H200 GPU 上达到 27.12 FPS，是唯一超过 24 FPS 实时播放速率的原生 T2AV 流式方法，比 JoyAI-Echo 快 8.8 倍、比 LTX2.3 快 14.8 倍。
- **音画同步与语音准确性保持**：Sync-C/Sync-D（6.62/8.95）和 WER（7.92%）接近离线双向 LTX2.3（6.80/7.96、7.59%），远优于其他流式 T2AV 基线（OmniForcing WER 98.79%、Hallo-Live 94.13%），证明显式语音规划对因果长时 T2AV 至关重要。
- **长时程身份保持**：约 2 分钟生成中，身份一致性指标几乎无下降（ArcFace 稳定在 0.73–0.77），且动态度保持较高（0.2588，增长 10%），表明并非通过静态画面换取稳定性。
- **两阶段训练缺一不可**：阶段二（因果初始化）防止运动崩塌；阶段三（长时 Self Forcing）支持高效 4 步推理并进一步提升同步、WER、漂移和身份指标。
- **上下文选择的关键作用**：3 个持久前缀块 + 1 个最近块的窗口设置在长时程生成中显著优于其他配置，持久上下文保持全局外观锚定，限制最近块数量可抑制自生成历史误差的累积。

## 7. 优点

- **问题定位精准**：清晰识别并系统解决两个关键困境（曝光偏差与因果语音规划缺失），论述有逻辑性。
- **方法设计务实高效**：采用后训练而非从零训练，复用已有双向基础模型的生成能力，符合大模型时代的部署逻辑。
- **三阶段训练流程层次分明**：从语料构建 → 因果化 → 长时程对齐，逐步弥合训练与推理之间的分布差距；混合 TF/DF、Self Forcing、DMD 蒸馏等技术选择均有充分动机。
- **语音规划设计巧妙**：将"说什么"与"怎么生成"解耦，利用现成语音 LLM 的规划能力，通过离散 token 与连续特征注入实现块级对齐，且支持语音中断/切换和静音监听，具备交互潜力。
- **评估全面**：兼顾质量、同步、语音准确率、动态度、身份一致性、长时程稳定性和推理速度；除聚合指标外还提供了时间轨迹分析，能揭示退化发生的时间点。
- **消融实验系统**：逐一验证每个关键设计决策的必要性，尤其是 Self Forcing 训练范围和上下文窗口的选择，具有很强的说服力。

## 8. 不足与局限

- **全合成训练数据**：训练语料完全由 LTX2.3 生成，可能继承基础模型的系统性偏差，缺乏真实音视频数据的验证，实际部署时泛化性未知。
- **对比公平性受限**：OmniForcing 和 Hallo-Live 仅能在 30 秒内运行，缺少同条件下约 2 分钟的公平对比；TIA2V 基线因其额外输入条件优势而难以直接作为参考。
- **缺乏人工评估**：所有指标均为自动计算，缺少主观观感（自然度、表达力、语音韵律等）的评估。
- **文本控制能力较弱**：方法仍依赖预训练 T2AV 能力（通过文本提示决定全局语义），Vorch-Streamer 只负责因果化后缀训练，对文本语义遵循度的提升有限。
- **身份一致性的局限性**：虽然 Human Identity / ArcFace 分数很高，但论文未展示多语言、多风格、多场景的大规模身份多样性评估。
- **语音规划依赖外部 LLM**：整体性能受 Fun-CosyVoice 规划能力的制约，若规划 token 预测不准确，同步质量会受影响；语音中断/切换能力未在实验中单独量化验证。
- **应用限制**：主要针对虚拟人头像场景（人物居中、类 vlog 风格），对其他类型音视频内容（多人物、复杂场景、动作剧烈）的适应性尚未验证。
