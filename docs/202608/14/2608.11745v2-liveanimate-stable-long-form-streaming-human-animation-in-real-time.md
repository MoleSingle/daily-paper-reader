## 摘要
姿态驱动的人体动画从单张参考图像和驱动姿态流中合成目标人物的视频。实时生成对于直播、远程临场和虚拟化身等交互式应用至关重要，然而基于扩散的系统每段视频需要几分钟到几小时，无法实现响应式交互。我们提出了LiveAnimate，据我们所知，这是首个将实时流式生成与十亿级稳定长时生成相结合的动画系统，构建于140亿参数的视频扩散Transformer（DiT）之上。两阶段训练流程首先通过参考锚定教师强制适应（Reference-Anchored Teacher-Forcing Adaptation）将预训练的双向DiT适配为块因果自回归生成器，然后通过块级自强制蒸馏（Block-wise Self-Forcing Distillation）将采样预算降至三步。为了在长流中保持外观一致性，我们引入了姿态检索汇注意力（Pose-Retrieval Sink Attention, PR-Sink），这是一种有界KV缓存机制，结合了永久锚定首生成块的静态汇（Static Sink）、保存姿态检索历史块的动态汇（Dynamic Sink）以及三槽滚动窗口。当姿态重复出现时，PR-Sink能够恢复相关外观上下文，而无需保留整个序列，因此无论流持续时间多长，内存和每块延迟都保持恒定。结合Ulysses序列并行和算子融合，这些设计使得在两个NVIDIA H100 GPU上实现19.63 FPS的流式推理。在三分钟基准测试中，LiveAnimate从最初30秒到最后一分钟几乎保持恒定的感知质量和身份一致性，而现有系统则明显退化或需要数小时的离线计算才能完成相同的生成。这些结果为交互式全身动画在质量、延迟和时长方面确立了新的操作点。

## Abstract
Pose-driven human animation synthesizes a video of a target person from a single reference image and a driving pose stream. Real-time generation is essential for interactive applications such as live streaming, telepresence, and virtual avatars, yet diffusion-based systems require minutes to hours per clip, precluding responsive interaction. We present LiveAnimate, to our knowledge the first animation system to combine real-time streaming with stable long-form generation at billion scale, built on a 14B-parameter video Diffusion Transformer (DiT). A two-stage training pipeline first adapts a pretrained bidirectional DiT into a block-causal autoregressive generator through Reference-Anchored Teacher-Forcing Adaptation, and then reduces the sampling budget to three steps through Block-wise Self-Forcing Distillation. To preserve appearance over extended streams, we introduce Pose-Retrieval Sink Attention (PR-Sink), a bounded KV-cache mechanism combining a Static Sink that permanently anchors the first generated block, a Dynamic Sink that holds a pose-retrieved historical block, and a three-slot Rolling Window. When a pose recurs, PR-Sink restores the relevant appearance context without retaining the entire sequence, so memory and per-block latency remain constant regardless of stream duration. Together with Ulysses sequence parallelism and operator fusion, these designs enable 19.63\,FPS streaming inference on two NVIDIA H100 GPUs. On a three-minute benchmark, LiveAnimate maintains nearly constant perceptual quality and identity from the first 30 seconds to the final minute, while prior systems degrade substantially or require hours of offline computation for the same rollout. These results establish a new operating point in quality, latency, and duration for interactive full-body animation.

## 二、方法论

### 核心思想
将预训练的 **双向视频扩散 Transformer 转化为块因果自回归生成器**，通过两阶段训练解决实时性与稳定性的矛盾，并设计有界 KV 缓存机制解决长流外观漂移问题。

### 关键技术细节

1. **Stage 1：参考锚定教师强制适应（Reference-Anchored Teacher-Forcing Adaptation）**
   - 将训练视频切分为时间块（每块 3 个潜在帧）；训练时每个块在去噪过程中关注 ground-truth 干净历史块，而非自身之前的预测，避免 Stage 1 阶段自回归误差进入条件上下文。
   - 关键创新是 **Ref Sink（参考汇）**：将参考图像潜在表示在干净时间步（t=0）前向编码，得到全局可见的 KV 状态，使所有生成块都能读取参考图像信息，维持身份和外观一致。
   - 注意力公式：`Attn(Qb, K, V) = softmax(Qb[Kref; K<b]^T / √d)[Vref; V<b]`，其中 Kref/Vref 来自参考帧，K<b/V<b 为教师提供的干净历史 KV。
   - **干净 KV 更新（Clean KV Update）**：推理时对去噪后的块在 t=0 再做一次前向，将 KV 写入缓存，确保历史状态与因果上下文处于一致的噪声水平。

2. **Stage 2：块级自强制蒸馏（Block-wise Self-Forcing Distillation, BS-DMD）**
   - 构建于 Self Forcing 方法之上，将采样预算从 50 步降至 3 步。
   - **Pass 1（无梯度自强制展开）**：学生模型在自身预测历史条件下生成完整轨迹，但**不保留反向传播图**。
   - **Pass 2（块级 DMD 优化）**：一次只重放一个块 T，该块的上下文从 Pass 1 轨迹中重建并 stop-gradient，仅当前块带梯度计算，然后对整个轨迹计算 DMD 损失。
   - 通过滑动 T 从 1 到 N 遍历所有块，使每个块都接收到分布匹配信号，同时避免保留完整展开图。
   - 配合 LoRA 适配，**14B 模型在单节点 8×80GB GPU 上即可完成蒸馏训练**。

3. **姿态检索汇注意力（Pose-Retrieval Sink Attention, PR-Sink）**
   - 解决流式生成中的“记忆-上下文困境”：保留全部历史 KV 导致线性增长的内存，有界缓存则会将外观信息永久丢弃。
   - 缓存结构（每层）：由四部分组成——
     - **Ref Sink**（全局参考图像 KV，永久固定）
     - **Static Sink**（首生成块，永久锚定，提供时间不变的外观锚点）
     - **Dynamic Sink**（姿态检索的历史块，由姿态匹配动态更新）
     - **三槽 Rolling Window**（最近两个干净块 + 当前块）
   - **置信度感知全身指纹**：用 ViTPose 提取 133 个全身关键点，将 3 帧姿态按帧拼接并 ℓ2 归一化，得到 558 维指纹（3×62×3），用于姿态相似度计算。
   - **多样性保持的记忆库更新**：库容量 M=5，替换策略为最小化平均成对余弦相似度，偏向覆盖新姿态；更新限制在前 20 个块。
   - **姿态最近邻检索**：生成前从库中检索与当前块指纹最相似的块 KV 写入 Dynamic Sink，排除 b−1（已在滚动窗口内）。
   - **位置一致的 KV 复用**：缓存未加 RoPE（旋转位置编码）的原始 K/V，注意力时按当前缓存布局重新旋转，解耦内容选择与原始时间戳。

4. **系统优化**
   - **Ulysses 序列并行**：每个 GPU 计算局部 token 的 Q/K/V 投影后，通过 all-to-all 通信切换为逐头并行布局，每层 2 次 all-to-all 操作。
   - **torch.compile**：以 `max-autotune-no-cudagraphs` 模式编译所有 DiT 块，预编译三个分辨率桶（480×480、672×384、384×672）。

## 三、实验设计

### 数据集与训练数据
- 训练数据：40k 说话视频（Looking to Listen 数据集）+ 20k 人体运动视频（如 HumanDID、X-Dance 等）。

### 评估基准
- 构建 **三分钟长视频基准**，包含 24 对参考图像和驱动视频，分两部分：
  - **Part 1**：12 个来自网络的 in-the-wild 视频，覆盖全身/上半身、多样外观和背景。
  - **Part 2**：12 个从 X-Dance 衍生的序列，通过正向-反向-正向播放驱动姿态以达到三分钟，使每个姿态在大时间间隔内重复出现，直接考验姿态重复下的身份一致性。
- 评估时划分时间窗口：0–10 秒前缀、0–30 秒初始窗口、30–90/90–120/120–180 秒三个非重叠后段，用以分离初始质量与累积退化。

### 评估指标
- **ASE**（美学分数）、**IQA**（图像质量评估，无参考）— 帧级视觉质量；
- **DINO-S**（DINO 相似度）— 与参考图像的身份一致性；
- **FID**、**V-MAE**（VideoMAE 特征距离）— 分布质量与时序表示误差。

### 对比方法
- EverAnimate、One-to-All、SCAIL、UniAnimate-DiT、Wan2.2-Animate。
- 对 SCAIL 和 UniAnimate-DiT 这类固定长度方法，采用 **训练-free 滑窗去噪扩展**（三角权重融合）公平对比。
- 消融实验：去除 Dynamic Sink（保留 Static Sink）、去除 Static Sink（保留 Dynamic Sink）、去除 RoPE follow、用传统教师强制替代 DMD 蒸馏、2/3/4 步采样对比。

## 六、主要结论与发现

1. **实时长时生成首次兼得**：LiveAnimate 是首个在 14B 参数规模下同时实现实时流式（~20 FPS）和稳定长时（3 分钟）姿态驱动人体动画的系统。
2. **质量稳定性显著优于对比方法**：从 0–30 秒到 120–180 秒，IQA 从 4.047 仅降至 4.026，ASE 从 2.823 保持至 2.824，DINO-S 仅下降 0.015（0.833→0.818）；而 One-to-All 的 IQA 从 3.402 崩溃至 1.786，DINO-S 从 0.769 降至 0.328。
3. **PR-Sink 两个 sink 互补**：Static Sink 提供时间不变的外观锚点（移除后 DINO-S 崩溃至 0.693），Dynamic Sink 恢复姿态相关外观证据（移除后 DINO-S 从 0.818 降至 0.805）。两者缺一不可。
4. **自强制蒸馏优于教师强制**：DMD 蒸馏版本终段 IQA 3.849 vs 教师强制的 3.438，DINO-S 0.780 vs 0.679，说明自强制有效减少少步采样下的误差积累。
5. **三步采样是最优权衡**：4 步质量略高但增加延迟，2 步身份保持变弱（终段 DINO-S 0.783），3 步兼顾效率与质量。
6. **扩展效率明确**：双卡速度提升 1.58 倍（效率 79.1%），四卡仅 1.78 倍（效率 44.6%），默认双卡配置最优。
7. **端到端效率的巨大提升**：baseline 生成同样的三分钟视频约需 2–5 小时，LiveAnimate 约 4 分钟，快约 30–75 倍。

## 七、优点

1. **问题定位精准**：准确识别出现有扩散式动画系统的关键差距（实时性 × 稳定性 × 长时性的三重矛盾），并明确了三者缺一不可。
2. **工程与算法结合紧密**：从蒸馏训练到推理系统优化形成了完整的闭环，不是单一的算法改进。
3. **PR-Sink 设计巧妙**：借鉴 LLM 中的 attention sink 思想，结合姿态检索机制，以恒定内存开销解决长流外观一致性问题，概念清晰、实现可落地。
4. **块级自强制蒸馏的可扩展性**：通过两遍回放和逐块梯度计算，使 14B 参数模型可在单节点完成蒸馏训练，解决了大规模蒸馏的显存瓶颈。
5. **评估设计相对严谨**：分段指标分析能区分初始质量与累积退化；姿态重复的三分钟基准设计（正-反-正播放）针对性地考验了长时一致性；对固定长度 baseline 采用统一的滑窗扩展以增强公平性。
6. **收益量化清晰**：消融实验和各组件耗时占比（PR-Sink 仅占 0.54%）有力证明了方法的高效性。
7. **报告透明**：明确说明了延迟测量范围（仅 DiT 生成循环，排除 VAE 编解码等），避免了误导性对比。

## 八、不足与局限

1. **分辨率限制**：目前仅支持 480×480 及两个竖向/横向变体，3 步采样限制了视觉保真度和分辨率的上限。
2. **场景覆盖有限**：不支持多人场景、大相机运动，姿态变化和面部表情的覆盖范围有限。
3. **训练数据规模相对不大**：仅 6 万条视频（4 万说话 + 2 万运动），对 14B 模型的泛化能力可能存在局限。
4. **评估基准规模有限**：24 个三分钟测试序列偏少，未报告统计显著性检验，结论的稳健性有待更大规模验证。
5. **baseline 对比的公平性在细节上仍存疑**：SCAIL/UniAnimate-DiT 的训练-free 扩展虽统一化处理，但可能未达其最优长视频性能；延迟对比排除了 VAE 等开销，虽说明理由但可能低估端到端延迟。
