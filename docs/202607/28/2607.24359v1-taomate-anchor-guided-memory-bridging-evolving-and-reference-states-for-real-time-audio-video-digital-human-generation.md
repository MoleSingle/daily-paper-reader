## 摘要
实时长形式数字人生成依赖于因果模型，在扩展音视频内容的同时保持主体外观和跨连续片段的音视频同步。有限缓存保留局部运动和语音上下文，但丢弃较早的证据，而关注完整生成历史计算成本高昂且会传播累积误差。我们提出\method，一种锚点引导的持久记忆框架，用于少步联合音频-视频生成。该框架保留不可变的视觉锚点，将已完成的视频和音频块压缩为固定容量的动态状态，并通过模态特定残差注意力检索这些状态，而不扩展活动缓存。一种参考感知调制方法额外地将视频特征条件化为动态和锚点外观统计量。锚点保持的因果上下文蒸馏改变展开范围、前缀来源和缓存历史可靠性，同时保持不可变视觉锚点不受干扰。通过将持久记忆与阶段局部去噪依赖分离，\method进一步允许跨块的阶段并行执行，加速自回归推理而无需特定管道的重新训练。我们评估长形式视频延续的外观、时间、同步、面部和语音诊断。结果表明\method在提示条件片段中保持稳定外观，并在自回归生成下保持强音视频同步。我们的项目页面是https://taoliveaigc.github.io/TaoMate。

## Abstract
Real-time long-form digital-human generation relies on causal models to extend audio-visual content while preserving subject appearance and audio-video synchronization across successive segments. A bounded cache retains local motion and phonetic context but discards older evidence, whereas attending to the complete generated history is computationally expensive and can propagate accumulated errors. We present \method, an anchor-guided persistent-memory framework for few-step joint audio-video generation. The framework preserves an immutable visual anchor, compresses completed video and audio blocks into fixed-capacity dynamic states, and retrieves those states through modality-specific residual attention without extending the active cache. A reference-aware modulation method additionally conditions video features on dynamic and anchor appearance statistics. Anchor-preserving causal-context distillation varies rollout horizon, prefix provenance, and cache-history reliability while keeping the immutable visual anchor unperturbed. By separating persistent memory from stage-local denoising dependencies, \method further admits stage-parallel execution across blocks, accelerating autoregressive inference without pipeline-specific retraining. We evaluate long-form video continuations with appearance, temporal, synchronization, facial, and speech diagnostics. Results show that \method preserves stable appearance across prompt-conditioned segments and strong audio-visual synchronization under autoregressive generation. Our project page is https://taoliveaigc.github.io/TaoMate.

- **现有方法局限**：因果蒸馏（如 Self-Forcing、Causal Forcing）能处理训练-测试上下文分布差异，但无法消除长期累积错误；滑动窗口或长上下文方法要么丢失历史，要么计算/存储随长度增长。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 核心思想
将历史信息分解为：
- **有界活动上下文** (bounded active context `C_{t-1}`)：保留最近的位置感知令牌，保证局部运动和语音连续性。
- **固定容量的持久记忆** (fixed-capacity persistent memory `M_{t-1}`)：压缩已完成块的分离表示，实现时长无关的长期条件化。

### 2.2 关键技术细节

#### （1）锚点引导的持久记忆（Anchor-Guided Persistent Memory）
- 记忆状态：`M_t = (a_v, a_a, m_v^t, m_a^t, κ_t, π_t)`
  - `a_v`、`a_a`：不可变视觉锚点和音频参考（从初始块提取）。
  - `m_v^t`、`m_a^t`：演变的视频/音频内容记忆（空间/声学结构）。
  - `κ_t`、`π_t`：归一化视觉内容的通道级和低频外观统计。
- **块表示分解**：将每块分解为归一化内容表示和未归一化外观表示，分离结构漂移和绝对外观漂移。
- **锚约束的记忆更新**：使用加权欧几里得重心公式：
  - `E(m, a, s; β, λ) = (1-λ)[(1-β)m + βs] + λa`
  - 系数 (1-λ)(1-β)、(1-λ)β、λ 分别控制历史、当前观测、固定锚点的权重。
  - 视频更新加入软置信门控 `g_t`：基于 s_v 与锚点的余弦相似度，抑制结构不一致的观测。
  - 外观统计结合软门控和硬拒绝规则，防止异常颜色/对比度直接传播。

#### （2）记忆条件化（Memory Conditioning）
- 内容记忆通过模态特定残差注意力（`MemAttn`）检索，不扩展活动缓存。
- 外观统计通过参考感知 FiLM（Feature-wise Linear Modulation）调控视频特征。
- 状态更新仅对最终干净块执行，梯度停止（stop-gradient），避免无限优化图。

#### （3）因果上下文蒸馏（Causal-Context Distillation）
- 使用混合展开视野（5块和10块）、学生生成的前缀、随机扰动非锚点历史（re-noise with σ∼U(0,0.15)）来模拟部署时上下文分布。
- 视觉锚点始终保持干净，防止身份信号弱化。
- 采用分布匹配蒸馏（DMD）和视频 PCM 一致性损失（相邻去噪过渡一致性）。

#### （4）记忆感知的阶段并行推理（Memory-Aware Stage-Parallel Inference）
- 将视频分窗，每窗维护固定干净前缀和持久记忆。
- 为每个去噪阶段分配一个 GPU/rank，独立维护阶段局部 KV 缓存。
- 块按反对角线波前推进，不同块在不同阶段并发处理，最终阶段连续输出干净块。
- 无需特定重新训练即可实现质量保持的加速。

## 7. 优点（方法或实验设计亮点）

- **创新记忆分解**：将长期记忆分为不可变锚点和自适应内容/外观状态，分别用注意力检索和 FiLM 调节，避免结构漂移与颜色漂移耦合。
- **高效推理架构**：训练无关的阶段并行（不修改模型）实现真实加速，且质量不降。
- **蒸馏策略**：通过混合展开、学生前缀、扰动非锚点历史模拟自回归误差，同时保护锚点不参与退化。
- **实验指标全面**：不仅包含音视频同步（LipSync/Desync），还设计长期一致性、颜色变化、面部稳定性等专用指标，更贴合长形式需求。
