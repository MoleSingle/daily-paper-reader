## 摘要
最近基于扩散的生成模型的进展实现了实时音频驱动的虚拟形象生成和统一的音频-视觉合成，为交互式虚拟形象系统提供了有前景的基础。然而，将这些模型扩展到实时交互式流式生成仍然具有挑战性，因为生成的时间范围事先未知，且在长期生成过程中跨模态身份一致性逐渐退化。为了解决这些挑战，我们提出了OmniMate，一个用于开放式实时交互式音频-视觉虚拟形象生成的统一框架。OmniMate实时联合合成视觉内容、语音和音频效果，实现自然且沉浸式的多轮交互。为了实现自适应响应进展，我们引入了一个生成进度控制器（GPC），它显式地对每个流式块的生成进度进行建模，使模型能够根据期望的进度完成响应，并在执行和倾听状态之间实现无缝切换。为了保持长期跨模态身份一致性，我们提出了一个多参考条件模块（MRCM），它利用多个参考图像和一个参考语音片段，在长时间流式交互中提供持久的视觉和说话人身份线索。在面向交互的VerseBench改编版上进行的广泛实验表明，OmniMate实现了高质量、低延迟的流式生成，同时保持了强大的长期音频-视觉一致性。结果进一步表明，OmniMate在扩展的多轮对话中支持逼真、连贯且响应迅速的交互式虚拟形象体验。

## Abstract
Recent advances in diffusion-based generative models have enabled real-time audio-driven avatar generation and unified audio-visual synthesis, providing a promising foundation for interactive avatar systems. However, extending these models to real-time interactive streaming remains challenging, as the generation horizon is unknown in advance and cross-modal identity consistency gradually degrades during long-term generation. To address these challenges, we propose OmniMate, a unified framework for open-ended real-time interactive audio-visual avatar generation. OmniMate jointly synthesizes visual content, speech, and audio effects in real time, enabling natural and immersive multi-turn interactions. To achieve adaptive response progression, we introduce a Generation Progress Controller (GPC) that explicitly models the generation progress of each streaming chunk, allowing the model to complete responses according to the desired progress and achieve seamless transitions between execution and listening states. To preserve long-term cross-modal identity consistency, we propose a Multi-Reference Conditioning Module (MRCM), which leverages multiple reference images and a reference speech segment to provide persistent visual and speaker identity cues throughout long-duration streaming interactions. Extensive experiments on an interaction-oriented adaptation of VerseBench demonstrate that OmniMate achieves high-quality, low-latency streaming generation while maintaining strong long-term audio-visual consistency. The results further show that OmniMate supports realistic, coherent, and responsive interactive avatar experiences over extended multi-turn conversations.

- **研究动机**：现有的扩散生成模型在实时音频驱动的虚拟形象生成和统一音视频合成方面取得了进展，但将其扩展到**开放式实时交互流式生成**面临两大挑战：
  - **生成时长未知**：在开放式的交互流中，模型无法预知当前响应何时结束，难以决定何时从“执行状态”（生成响应）无缝切换到“监听状态”（等待用户输入）。固定时长会导致截断或冗余，而显式完成检测则会引入额外延迟。
  - **长期跨模态身份一致性退化**：由于流式生成只保留有限的时序上下文，视觉身份线索（如面部特征）和说话人身份线索（如音色）会随时间逐渐漂移，导致多轮对话中虚拟形象外观和声音不一致。

- **整体含义**：论文旨在解决上述挑战，提出一个统一的框架 **OmniMate**，能够**实时联合生成语音、面部动作、身体姿态以及动作相关音效**，并保持长期的身份一致性，从而支持**自然、沉浸的多轮交互式虚拟形象**。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 核心思想
OmniMate 基于扩散模型，引入两个核心模块：
- **生成进度控制器（GPC）**：显式建模每个流式块的生成进度，使模型能感知当前响应是否已完成，从而实现自适应响应终止和状态切换。
- **多参考条件模块（MRCM）**：利用多个参考图像和一段参考语音，在长期流式生成中提供持久的视觉和说话人身份线索，防止身份漂移。

整个框架采用蒸馏后的因果注意力架构，结合 DMD（Distribution Matching Distillation）实现实时推理。

### 2.2 关键技术细节

#### (a) 生成进度控制器（GPC）
- **进度映射**：由 LLM 预估执行时长，据此计算每个视频帧和音频 token 的进度值（1~1000）。视频帧进度公式：
  \[
  p_i^v = 1 + \frac{i-1}{T_v-1} \times 999, \quad i=1,\dots,T_v
  \]
  音频进度类似定义。超过预估时长的 token 进度值设为 0（表示监听状态）。
- **注入方式**：进度值经 Sinusoidal Positional Encoding 和 MLP 编码后，**加到对应的潜变量上**：
  \[
  \tilde{z}_m = z_m + \text{MLP}(\text{PE}(p_m)), \quad m \in \{a,v\}
  \]
- **状态转换数据构建**：使用 DMD 蒸馏后的双向教师模型生成包含执行→监听、监听→执行等状态切换的序列，并采用分段交叉注意力掩码（执行部分关注执行提示词，监听部分关注通用监听提示词）。使用蒸馏后的教师而非原始多步教师，以避免跨边界语义泄漏。
- **联合训练**：先 ODE 初始化（学生模型仅靠进度控制状态切换，受监督于状态转换序列），再用 DMD 蒸馏进一步优化，使学生模型能通过进度条件自主控制状态。

#### (b) 多参考条件模块（MRCM）
- **视觉身份条件**：将 N 个参考图像的潜变量与当前噪声视频潜变量沿时间维度拼接（公式 7），并应用负 RoPE 避免影响生成帧位置。训练时随机采样 4 个身份帧，推理时最多使用 4 个参考图像。
- **说话人身份条件**：采用免训练策略——在去噪过程中，将生成的首段语音潜变量**替换为参考语音潜变量**（公式 8）。若无参考音频，则保持生成音频不变。通过持续保留参考语音潜变量，维持稳定的说话人特征。

#### (c) 训练与推理流程
- **训练四阶段**：
  1. 微调 LTX‑2.3（添加视觉身份条件）。
  2. 用 DMD 蒸馏出一个快速双向教师模型，并构建状态转换 ODE 轨迹。
  3. ODE 初始化：联合优化 GPC 和学生模型，使用因果注意力掩码。
  4. 自强制 DMD 蒸馏：每个生成块只允许关注参考块、首个块和两个相邻块，强制自回归行为。
- **推理**：LLM 根据用户输入生成响应内容和预估时长；GPC 将时长转为进度信号引导生成；MRCM 提供身份条件；使用 RollingSink 维持长期视觉稳定性。

## 3. 实验设计

### 3.1 数据集

  - 公开讲话头部数据集：HDTF、VFHQ、VoxCeleb2、CelebV-Text、AVSpeech。

## 6. 论文的主要结论与发现

- OmniMate 在**生成速度**（27.64 FPS）和**首帧延迟**（3.49s）上显著优于所有对比方法和实时基线，达到实时交互要求。
- 在**音视频质量**和**身份一致性**方面，OmniMate 在 A-ID、V-ID、IB-Score 等指标上取得最优或次优，表明能保持长期稳定的外观和音色。
- **状态转换**：定性结果显示 OmniMate 能实现自然平滑的执行-监听切换，而对比方法（如 OmniForcing、Hallo-Live）会出现延迟或错误动作。
- **消融验证**：GPC 和 MRCM 均为关键组件，缺少任一都会导致身份漂移、状态转换失败或生成质量下降；在 240 秒长序列中仍保持稳定，证明其适用于长时间交互。
